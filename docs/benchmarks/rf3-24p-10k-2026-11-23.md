# Rusta RF3 benchmark: 24 partitions at 10k messages/s

**Best observed ACK p95: 43.3 ms**

Rusta's durable RF3 profile recorded this p95 in a 60-second measured window with 24 partitions and a mixed 1 KiB produce-and-consume workload. The page reports the best observed window as a best-case result. It does not claim this latency is typical or guaranteed.

[Performance overview](../performance.md)

## Best-window measurements

| Metric | Result |
| --- | ---: |
| Offered rate | 10,002 messages/s |
| Acknowledged rate | 9,999 messages/s |
| Consumed rate | 9,998 messages/s |
| ACK p95 | **43.3 ms** |
| ACK p99 | 66.8 ms |
| End-to-end p99 | 103.5 ms |
| Unread records | 0 at start → 200 at end; sampled peak 1,558 |

All 640,000 records submitted in the run, including warmup, were acknowledged, consumed, committed and checked by partition offset and payload sequence after draining.

## Configuration

| Item | Setup |
| --- | --- |
| Rusta revision | `d0f8c9b209bf5a29b6a17db93f1432fe63153402` |
| Replication | Three brokers, durable Raft majority acknowledgments |
| Broker limits | 1 vCPU and 1 GiB RAM per broker |
| Host | Apple M5, 16 GiB RAM |
| Docker VM | ARM64, four vCPUs, 7.75 GiB RAM |
| Client | Kafka Java 4.1.2, one producer and one consumer |
| Payload and partitions | 1 KiB, 24 round-robin partitions |
| Producer | Idempotence enabled, `acks=all`, `linger.ms=1`, no compression |
| Consumer | `fetch.max.wait.ms=10` |
| Measurement | 4 seconds warmup, 60 seconds measured |
| Rusta disk workers | 8; ACK profiling disabled |

The client measures ACK latency from immediately before record submission until broker acknowledgment. End-to-end latency measures submission through consumer delivery in the same client process. The brokers ran as containers on one local Docker VM, so this result is for a single-host environment.

## Reproduce

Build the recorded revision, then run the Rusta durable profile with the same workload settings:

```sh
docker build -t rusta:rf3-24p-10k \
  --build-arg RUSTA_REVISION=d0f8c9b209bf5a29b6a17db93f1432fe63153402 .

python3 tests/bench/compare.py /tmp/rusta-24p-10k \
  --profiles rusta-rf3-durable --rusta-image rusta:rf3-24p-10k \
  --partitions 24 --workloads mixed --rate 10000 --seconds 60 \
  --idle-seconds 6 --repeat 1 --linger-ms 1
```
